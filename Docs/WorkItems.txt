(DONE) 13. [HBE] Add CPU Frame and System Timing

The profiler must be optional in release builds or have negligible overhead when disabled. Expose the results through a public data structure; do not create an engine profiler window. This item is complete when MegaX can time at least five nested systems and read accurate millisecond values after every frame.
